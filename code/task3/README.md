# Task 3: SPV-Augmented Neural Metaphor Detector

**Project:** Project 11 — Metaphor Detection  
**Dataset:** TroFi  
**Task weight:** 40 marks

## Objective

Task 3 tests whether the neural model benefits from the classical
selectional-preference signal from Task 1.

It implements three required analyses:

1. Point-biserial correlation between Task 1 `association_score` and Task 2
   correctness.
2. A BiLSTM augmented with the normalized SPV association score and a
   cold-start indicator.
3. Evaluation on the Task 1/Task 2 disagreement subset.

The implementation uses exact `sentence_id` joins. It fails explicitly if
Task 1 and Task 2 artifacts contain different examples.

## Augmented Architecture

The Task 3 model retains the Task 2 architecture:

```text
GloVe + ELMo
      |
2-layer BiLSTM
      |
target verb hidden state (600 dimensions)
      |
concatenate:
  normalized association_score
  cold_start_flag
      |
dropout
      |
binary classifier
```

The augmented classifier therefore receives 602 features:

```text
600 BiLSTM features + 2 SPV features
```

The association score is normalized using only the training split:

```text
score_normalized = (score - train_mean) / train_std
```

The same training mean and standard deviation are used for validation and
test. If the training standard deviation is zero, it is replaced by `1.0`.
The cold-start indicator is passed as a second scalar feature without
normalization.

## Files

### `common.py`

Provides:

- Exact Task 1 feature validation
- Sentence-ID alignment
- Training-only feature normalization
- Metric calculation
- Shared imports for the Task 2 modules

### `correlation.py`

Computes the point-biserial correlation. Since neural correctness is binary,
this is calculated as the Pearson correlation between:

```text
association_score
is_correct
```

The result is written to:

```text
checkpoints/task3/correlation.json
```

### `augmented_model.py`

Trains the SPV-augmented model with:

- Adam
- Learning rate `0.001`
- Two BiLSTM layers
- Hidden size `300` per direction
- Dropout `0.5`
- Validation-F1 early stopping
- Patience `5`
- Seed `42`

Outputs:

```text
checkpoints/task3/
├── best_model.pt
├── history.json
├── test_metrics.json
└── test_predictions.csv
```

### `disagreement_analysis.py`

Restricts evaluation to examples where Task 1 and Task 2 disagree. It reports
separate results for:

- Task 1 correct and Task 2 incorrect
- Task 1 incorrect and Task 2 correct

Output:

```text
checkpoints/task3/disagreement.json
```

### `evaluate_task3.py`

Creates a single comparison of Task 1, Task 2, and Task 3 on the same test
examples:

```text
checkpoints/task3/comparison.json
```

### `run_task3.bat`

Runs correlation, augmented training, disagreement analysis, and final
comparison on Windows.

## Running Task 3

First ensure Task 1 and Task 2 have been completed. Then run:

```powershell
python code\task3\correlation.py
```

Train and evaluate the augmented model:

```powershell
python code\task3\augmented_model.py `
  --train_path data\trofi_train.csv `
  --val_path data\trofi_val.csv `
  --test_path data\trofi_test.csv `
  --train_features data\task1\spv_scores_train.csv `
  --val_features data\task1\spv_scores_val.csv `
  --test_features data\task1\spv_scores_test.csv `
  --glove_path data\embeddings\glove.840B.300d.txt `
  --elmo_options data\embeddings\elmo_2x4096_1xhighway_options.json `
  --elmo_weights data\embeddings\elmo_2x4096_1xhighway_weights.hdf5 `
  --save_dir checkpoints\task3
```

Run the analyses:

```powershell
python code\task3\disagreement_analysis.py
python code\task3\evaluate_task3.py
```

Or run the complete Windows pipeline:

```bat
code\task3\run_task3.bat ^
  data\embeddings\glove.840B.300d.txt ^
  data\embeddings\elmo_2x4096_1xhighway_options.json ^
  data\embeddings\elmo_2x4096_1xhighway_weights.hdf5
```
