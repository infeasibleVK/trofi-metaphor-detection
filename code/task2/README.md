**Course:** CS60075 Natural Language Processing (Assignment II)  
**Project:** Project 11 — Metaphor Detection  
**Dataset:** TroFi (Trope Finder)  
**Assigned Weightage:** 30 Marks

## 1. Objective

Task 2 reproduces the neural metaphor detector described in:

> Gao, Choi, Choi, and Zettlemoyer, “Neural Metaphor Detection in Context,” EMNLP 2018.

For TroFi, this is a **target-word classification** problem. Each sentence contains one ambiguous target verb, and the model predicts:

```text
0 = literal
1 = metaphorical / nonliteral
```

Unlike the VUA version of the project, Task 2 does not predict a label for every token. It extracts the contextual representation of the target verb and classifies only that word.

---

## 2. Dataset Interface

Task 2 uses the files generated by Task 1 preprocessing:

```text
data/trofi_train.csv
data/trofi_val.csv
data/trofi_test.csv
```

The loader supports the Task 1 schema:

| Column | Meaning |
|---|---|
| `sentence_id` | WSJ source identifier |
| `target_verb` | Base form of the ambiguous verb |
| `target_idx` | Token index of the target verb |
| `target_token` | Surface form in the sentence |
| `label` | `0` literal, `1` metaphorical |
| `sentence` | Tokenized sentence |
| `cluster` | Original TroFi cluster |

The optional `tokens` column is also supported. If it is absent, the sentence is split on whitespace. The loader accepts `target_idx`, `target_index`, `verb_idx`, or equivalent names.

The split is the fixed sentence-level 80/10/10 split created by Task 1 with seed `42`. The test set is never used for training or early stopping.

## 3. Model Architecture

The implementation is in [model.py](./model.py).

```text
Sentence tokens
      |
      +--> 300-dimensional GloVe embedding
      |
      +--> 1024-dimensional ELMo embedding
                    |
        Concatenate GloVe + ELMo
                    |
        2-layer bidirectional LSTM
        hidden size = 300 per direction
                    |
       Select output at target_idx
                    |
              Dropout = 0.5
                    |
             Linear classifier
                    |
        Literal / metaphorical logits
```

The input size to the BiLSTM is:

```text
300 + 1024 = 1324
```

The BiLSTM output at the target position has size:

```text
300 * 2 = 600
```

This 600-dimensional contextual target representation is passed through dropout and a two-class linear layer.

### Embeddings

The implementation uses:

- `glove.840B.300d.txt`
- ELMo options file
- ELMo weight file

GloVe vectors are loaded by [embeddings.py](./embeddings.py). Padding is assigned index `0`, and unknown words use the mean GloVe vector. GloVe is frozen by default. ELMo is used as a frozen contextual feature extractor.

### ELMo dependency

ELMo is loaded lazily through AllenNLP. This means importing the Task 2 modules does not require AllenNLP, but training and evaluation do.

## 4. File-by-File Implementation

### `dataset.py`

Provides:

- `TroFiExample`
- `TroFiDataset`
- CSV loading
- target-index validation
- serialized-token parsing
- padding and batching
- batch-level target indices and labels

The collator creates padded token ID tensors while preserving the original token lists for ELMo.

### `embeddings.py`

Provides:

- `load_glove()`
- `ElmoEncoder`

`load_glove()` builds a vocabulary and embedding matrix. `ElmoEncoder` converts token lists to character IDs and returns contextual ELMo representations.

### `model.py`

Provides `TroFiBiLSTM`, which:

1. Looks up GloVe vectors.
2. Concatenates them with ELMo vectors.
3. Encodes the sequence with a two-layer BiLSTM.
4. Selects the hidden state at `target_idx`.
5. Applies dropout.
6. Produces two-class logits.

### `train.py`

Provides:

- Reproducible random seeding
- Training and validation loops
- Adam optimization
- Validation metaphor F1 calculation
- Early stopping
- Best-checkpoint saving
- Training-history JSON output

Default training settings:

| Setting | Value |
|---|---:|
| Optimizer | Adam |
| Learning rate | `0.001` |
| BiLSTM layers | `2` |
| Hidden size per direction | `300` |
| Dropout | `0.5` |
| Maximum epochs | `30` |
| Early-stopping patience | `5` |
| Batch size | `16` |
| Seed | `42` |

The best checkpoint is selected using validation F1 for the metaphor class.

### `evaluate_task2.py`

Loads the best checkpoint and reports:

- Accuracy
- Literal precision, recall, and F1
- Metaphor precision, recall, and F1
- Macro F1
- Confusion matrix

The output is printed as JSON and saved as:

```text
checkpoints/task2/test_metrics.json
```

### `run_task2.bat`

Runs training followed by test evaluation on Windows.

## 6. Running Task 2

### Training

```powershell
python code\task2\train.py `
  --train_path data\trofi_train.csv `
  --val_path data\trofi_val.csv `
  --glove_path data\embeddings\glove.840B.300d.txt `
  --elmo_options data\embeddings\elmo_2x4096_1xhighway_options.json `
  --elmo_weights data\embeddings\elmo_2x4096_1xhighway_weights.hdf5 `
```

### Evaluation

```powershell
python code\task2\evaluate_task2.py `
  --test_path data\trofi_test.csv `
  --model_path checkpoints\task2\best_model.pt `
  --glove_path data\embeddings\glove.840B.300d.txt `
  --elmo_options data\embeddings\elmo_2x4096_1xhighway_options.json `
  --elmo_weights data\embeddings\elmo_2x4096_1xhighway_weights.hdf5
```

```bat
code\task2\run_task2.bat ^
```

## 8. Evaluation Protocol

The main reported metric is F1 for the metaphorical class because the project specifically evaluates metaphor detection.

Report the following:

1. Metaphor precision
2. Metaphor recall
3. Metaphor F1
4. Accuracy
5. Confusion matrix
6. Macro F1
7. F1 by POS

For TroFi, every target is an ambiguous verb, so the POS breakdown is reported as:

```text
Verb F1 = overall target-word F1
```

The Task 2 test results must be compared with Task 1 using exactly the same `trofi_test.csv`.

## 10. Reproducibility and Limitations

To reproduce the experiment:

1. Generate the Task 1 splits.
2. Place the GloVe and ELMo files at the documented paths.
3. Use the same seed, split files, and command-line settings.
4. Train and select the best checkpoint using validation F1.
5. Evaluate once on the held-out test split.

Important limitations:

- TroFi is relatively small, so results may vary with the random seed.
- The fixed split is required by this assignment but differs from common published cross-validation protocols.
- ELMo and dependency versions can affect numerical results.
- Unknown words use a fallback GloVe vector.
- The model classifies one target verb per sentence and does not perform full sentence sequence labeling.
